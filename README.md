# ShelfReady Studio — downloads

This repository exists only to host **downloads** for the ShelfReady Studio desktop app:

- the Windows installer for each version, and
- `latest.json`, the small file the installed app reads to discover updates.

The app's source code is **not** in this repository.

## Install

Download the newest installer from the [**Releases**](../../releases/latest) page and run it.

## Updates

The desktop app checks here each time it starts and offers any newer version automatically. You do not
need to come back to this page after installing.
